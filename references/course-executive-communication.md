# 共修专项 · 与一号位沟通：从建立信任到企业试点

**这门课要让学生带走的一件事**：面对企业一号位时，不因身份、身价或企业规模妄自菲薄；站在对方的收益、风险与机会成本上思考，把 AI 技术翻译成业务产品，并把一次沟通推进成有数据、有指标、有负责人的真实试点。

这不是销售话术课，也不以成交为唯一目标。清楚表达、守住边界、识别不适配，同样是专业结果。

按 `references/pedagogy.md` 的课本式讲授教。课程只有三节，依次对应**会前、会中、会后推进**；文件编号是兜底路径，不限制动态排课。

## 图谱与接入信号

兜底路径：01 → 02 → 03。

- 明天就要见老板 → 01 快讲，直接产出机会卡和 30 秒表达。
- 已收到客户消息、会议记录，或正在面对竞品/质疑 → 直接进 02。
- 客户已明确有意愿，正在讨论数据、报价或 POC → 直接进 03。
- 当前联系人不是最终决策人 → 先讲 01 的“一号位门槛”，不要继续免费写完整方案。
- 纯技术背景、习惯用“很难、准确率不够”证明能力 → 02 重点练技术难度翻译。
- FDE 学生准备进真实企业现场 → 九宫格之后、实战之前接入本专项。
- AI Native 学生准备接企业项目 → 完成产品构建认知后接入。

## 综合模拟

三节完成后，从场景库运行“综合模拟”：

1. 非一号位联系人要求完整方案；
2. 学生争取见业务一号位；
3. 用 30 秒表达价值；
4. 老板拿竞品比较；
5. 老板要求百分之百承诺；
6. 老板担心员工不配合；
7. 学生推进一个有边界的试点。

综合模拟不是第四节课。低于可进入真实会谈的标准时，只重练最弱项。
