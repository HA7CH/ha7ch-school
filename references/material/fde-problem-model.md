# 候选素材 · 勘探的产出物是问题模型,不是一堆笔记

> 整理日期:2026-09-14。素材层,供 FDE 课维护者评审;未进入讲义、诊断评分、学生端或托管站。
> 来源:一支驻场 FDE 团队的内部方法论中「勘探」阶段的核心框架,用整理者自己的话转述,不引用原文;加一段本次新设计的练习。已在 `HA7CH/ai-native-company` PR #13 里作为 vault 的诊断层落地(SPEC §2.5),这里是它的教学版。

## 一、为什么值得补进 School

FDE 课把 Echo 定义为"摸真需求",货代擂台让学生练一次 Echo。但 Echo 的**产出物**长什么样,讲义没有给结构。学生的常见状态是:访谈记了很多、拍了很多照片、笔记散成一堆,回来不知道该先做什么。这份素材补的就是那个结构。

一句话:**勘探的本质不是收集信息,而是建立问题模型。** 信息是无限的,一个制造企业几十个部门几百个岗位,穷尽信息三周还在访谈第三个部门;没有结构容纳信息,再多笔记也驱动不了设计决策。

## 二、问题模型的五个要素

问题模型是对客户业务里"哪里堵了"的结构化描述。合格的问题模型必须有五样东西:

| 要素 | 回答的问题 | 学生最容易漏掉的 |
|---|---|---|
| **核心瓶颈** | 制约客户业务目标达成的关键环节是什么 | 把老板说的"想用 AI"当瓶颈;瓶颈必须落到一个具体环节 |
| **因果链** | 这个瓶颈由什么导致:技术原因还是流程原因,外部约束还是内部能力不足 | 只写现象不写原因;或者原因全归到"没有系统" |
| **量化影响** | 这个瓶颈让客户损失了什么:时间、收入、满意度;能度量吗 | 用员工口头估计冒充实测;劳动时间和等待历时混在一起 |
| **相关方地图** | 谁被影响、谁有动力推动解决、谁会阻碍改变 | 只画支持者,不画阻碍者;分不清主裁和盟友 |
| **已有尝试** | 客户之前试过什么,为什么失败 | 完全不问,然后把失败过的方案再做一遍 |

好的问题模型能穿过客户的表面表述。客户说"客服压力大",问题模型说"八成咨询集中在三个高频问题,其中两个可以用知识库解决";客户说"数据分析效率低",问题模型说"数据散在四个系统,每周手工导出合并、人工核对一致性"。货代擂台里真相的形态也是这样:老板说"要 AI 全自动",问题模型说"跟单员每天肉眼对单、做账最烧脑最赔钱,该做轻量增量插件,不是重做 ERP"。

## 三、和现有框架的关系

- **Echo 的产出物就是问题模型。** 第 1 课说 FDE 拥有问题定义权,问题模型就是那个"定义"的载体;没有它,问题定义权是一句空话。
- **九宫格决定问题模型的粒度。** 第一层(30 人)的问题模型只需要一个核心瓶颈和一条因果链;第二层(200 人)要画到跨部门的相关方地图;第三层(国央企)的相关方地图本身就是一份交付物。
- **一号位沟通专项的会前功课,就是问题模型的第一版假设。** 见面前每个要素都标"假设",见面后逐条变成"已验证"或"已推翻"。
- **`fde-diagnosis` 里的三道探针**(假需求题 / 经济账题 / 薄切片题)分别对应核心瓶颈、量化影响、已有尝试三个要素——诊断器其实一直在测学生会不会建问题模型,只是没有把这个名字说出来。

## 四、诊断期怎么用它(来自真实试点的做法,已去身份)

在一个 200 人层制造企业的一阶段里,问题模型不是一次写完的文档,而是带状态的活文件:

1. 每个要素带 `状态: 假设 / 已验证 / 已推翻` 和证据链接(访谈纪要、数据表、流程文件)。
2. 创始人或老板访谈只给假设;逐人访谈(bot 或人)给证据。
3. 第一批要做的工具和 bot,每一个回指问题模型的一个要素——比如"把采购周报还原成任务级甘特图"对应的是相关方地图里"管理层看不到任务级进度"这一条。
4. 每个里程碑复盘先看哪些假设变成了已验证或已推翻,再谈交付;推翻的要素改问题模型,不改方案 PPT。

## 五、可选练习:给货代擂台写问题模型

**以下为教学设计,用的是 Lab B 已有的合成案例,不对应真实客户。**

学生打完货代擂台、提交诊断之前,先用五个要素写一页问题模型:

- 核心瓶颈:一句话,落到具体环节(对单?做账?托书?)。
- 因果链:至少三条,每条标技术 / 流程 / 外部 / 能力。
- 量化影响:写出你在对话里拿到的每一个数字,并标注它是谁说的、是估计还是实测;老板那句"一年省十几万"必须标"未验证"。
- 相关方地图:四个 NPC 各一行,立场(推动 / 中立 / 阻碍)和动机。
- 已有尝试:业务员说的"发链接让客户填托书"算不算已有尝试?为什么不算创新?

建议验收:五个要素齐;核心瓶颈不是老板的原话;量化影响里没有一个未标来源的数字;相关方地图里至少有一个阻碍者。**问题模型写不出核心瓶颈的学生,通常是在对话里被跟单员的细节漩涡带走了——这是一个比擂台评级更早的信号。**
